# 实验结果与边界

此页记录2026-10-17的历史本地实验。汇总数据另见`results/summary.json`。
原始训练集、验证对话、预测文本、服务器日志及模型文件不随本仓库分发。
因此仓库提供复现流程和汇总证据，不保证仅凭clone即可重现这些数值。

## 主训练

Qwen2.5-7B-Instruct，QLoRA NF4/BF16，LoRA rank16/alpha32，batch1、梯度累积8、
4096上下文、学习率1e-4，完成2245 optimizer steps。
18657条官方训练样本中17960条符合长度限制，697条排除。
固定64条验证loss的最佳checkpoint为2100，loss约1.00862。

## 冻结候选的1802条比较

候选选择集552条来自179个对话组；确认部分1802条来自另外721个对话组。
该分区只针对本次候选选择与生成评估，数据此前已被处理过，不能称官方隐藏测试。
此后已经查看结果，不能反复调参后继续称其独立确认。

| 指标 | 配对原运行时 | v2方案 |
| --- | ---: | ---: |
| 情绪Acc | 77.30% | 77.58% |
| 画像三个维度平均集合精确匹配 | 61.04% | 64.48% |
| BLEU-4 | 13.87 | 13.93 |
| ROUGE-L F1 | 29.07 | 29.10 |
| 空回复 | 6 | 0 |

比较复用同一首轮模型输出：原运行时对无效首轮结果按旧解析器处理，
候选只在异常时重试，并在CPU上替换style字段。7条发生重试。
画像差值按对话组配对bootstrap的95%百分位区间约为+2.20至+4.64个百分点，
反映这批公开样本的抽样不确定性，不保证隐藏测试增益。

候选前100条平均耗时3029.29 ms、P95 8213.76 ms。
没有另测对照模型同批端到端延迟，不能宣称候选更快。
BERTScore未测，官方指标组合和计分公式未确认，不能据此给出官方总分。
